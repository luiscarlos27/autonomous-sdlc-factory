# Spec Delta

## Purpose

Defines secure execution environment using gVisor with OPA/Rego policy enforcement for untrusted code generated by agents.

## ADDED Requirements

### Requirement: Untrusted code runs in isolated sandbox
The system SHALL execute untrusted generated code within gVisor-isolated containers.

#### Scenario: Sandbox isolation
- **WHEN** untrusted code executes
- **THEN** it runs with restricted syscall access via gVisor

#### Scenario: Resource constraints
- **WHEN** code runs in sandbox
- **THEN** resource limits are enforced

### Requirement: Policy enforcement via OPA
The system SHALL validate execution against security policies defined in Rego via Open Policy Agent.

#### Scenario: Policy validation before execution
- **WHEN** execution is requested
- **THEN** OPA validates against security.rego policies

#### Scenario: Block policy violations
- **WHEN** code violates security policies
- **THEN** execution is blocked with policy violation details
