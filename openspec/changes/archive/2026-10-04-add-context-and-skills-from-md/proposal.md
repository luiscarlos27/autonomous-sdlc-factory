# Proposal

## Why

The root directory contains two additional MD files: `resumen_agente_referencia.md` (comprehensive research/reference on agentic engineering) and `skill_agentic_engineering_weekly.md` (weekly practice skill). These contain valuable context about the theory, evolution, and practical workflows for agentic engineering. We need to analyze them, extract useful knowledge, create appropriate OpenSpec specs/skills, and integrate this context into the project to enrich agent understanding.

## What Changes

- Create capability specs for key governance and context management concepts from research
- Convert the weekly skill into an opencode skill with proper format
- Add the weekly practice skill to .opencode/skills/
- Enhance existing specs with research insights

## Capabilities

### New Capabilities

- `agent-governance`: Agent drift control, policy enforcement, safety mechanisms, and DoD enforcement
- `context-management`: Long-term memory, context compression, and drift prevention strategies

### Modified Capabilities

- `refactor-guardian`: Enhance with stronger anti-snowball/complexity control
- `observability`: Enhance with agent drift detection and governance metrics

## Impact

- Adds richer context for AI agents working on the project
- Creates additional specs aligned with the research findings
- Integrates the weekly practice skill as an opencode skill
- Strengthens existing specs with empirical insights
